# Migrate from v0.3.0

In this section, we will introduce how to upgrade from v0.3.0.

If you are a user of the old version React APP, please perform the correct operations according to your specific situation:

- If you have not made any code modifications, just pull the v0.4.0 Tag and rebuild and deploy. This upgrade will be seamless for you
- If you have modified the code and want to use the new features in the current version, please follow the steps below to upgrade

:::warning
In v0.4.0, we completely deprecated `DifyChatProvider` and `useDifyChat`, which simplifies component nesting relationships.

The configuration initialization functionality originally carried by `DifyChatProvider` has now been split into several parts.
:::

## 1. Initialize Running Mode

In `packages/react-app/src/App.tsx`, initialize the running mode:

```tsx title="packages/react-app/src/App.tsx"
// Initialize global runtime configuration
difyChatRuntimeConfig.init('multiApp')
```

## 2. Initialize Application Configuration Management Service

The application configuration management service will now be automatically imported when needed. According to different running modes, the entry points are as follows:

- Single-app mode: `/packages/react-app/src/services/app/singleApp/index.ts`
- Multi-app mode: `/packages/react-app/src/services/app/multiApp/index.ts`

What you need to do is export the `appService` you use in the entry file above.

Taking multi-app mode as an example:

```ts title="packages/react-app/src/services/app/multiApp/index.ts"
import DifyAppService from './localstorage'

export const appService = new DifyAppService()
```

## 3. Initialize `userId` and `enableSetting`

In v0.4.0, a real authorization login page was added. You can check the [Custom User Information](https://docs.dify-chat.lexmin.cn/guide/app-config/custom-user-info.html#%E8%87%AA%E5%AE%9A%E4%B9%89%E7%94%A8%E6%88%B7%E4%BF%A1%E6%81%AF) documentation to customize your user information retrieval and update logic.
