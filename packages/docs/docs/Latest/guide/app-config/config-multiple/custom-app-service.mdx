# Custom Application Configuration Management

For demonstration purposes, in the React SPA version, we default to using LocalStorage for application configuration management, while in the Next.js version, we default to using local JSON files.

If you want to customize the application configuration management service, please read the following content.

## Determine Running Mode

Before starting configuration, ensure your running mode is multi-app mode.

<Tabs>
  <Tab label="React SPA">
```tsx title="packages/react-app/src/App.tsx"
// Initialize global runtime configuration
difyChatRuntimeConfig.init('multiApp')
```
	</Tab>
  <Tab label="Next.js">
```bash title="packages/nextjs-app/.env"
# Running mode
RUNNING_MODE=multiApp
```
	</Tab>
</Tabs>

## Custom Application Configuration Management

### React SPA Version

#### Configuration Entry

```tsx title="packages/react-app/src/services/app/multiApp/index.ts"
// Default uses LocalStorage storage
import DifyAppService from './localstorage';

export const appService = new DifyAppService();
```

#### Built-in Implementations

**1. LocalStorage**

Uses LocalStorage for data storage. When users switch browsers, data will be lost. Only for demonstration purposes.

**2. Static Data**

Uses static data for storage, only supports querying, does not support modifying data. Suitable for scenarios where users don't need to customize applications.

Define the list of applications accessible to users:

```ts title="packages/react-app/src/services/app/multiApp/static-readonly/data.ts"
import { AppModeEnums, IDifyAppItem } from '@dify-chat/core'

/**
 * Static application list for demonstration
 */
export const staticAppList: IDifyAppItem[] = [
	{
		// Application unique identifier, just ensure it's not duplicated
		id: '0.270357011315995',
		// Application information, including name, description, tags, mode, etc.
		info: {
			// Application name
			name: 'My Chatflow APP',
			// Application description
			description: 'My Chatflow Application',
			// Application tags
			tags: [],
			// Application mode
			mode: AppModeEnums.CHATFLOW,
		},
		// API request configuration, including API Base and API Key
		requestConfig: {
			// API Base address
			apiBase: 'https://api.dify.ai/v1',
			// API key
			apiKey: 'app-xxxxxxx',
		},
	},
]
```

**3. Restful API**

Gets and modifies data through interfaces, recommended🌟

The default backend service address is `http://localhost:5300`. You can modify it according to your needs.

Start backend service:

```bash title="packages/server"
pnpm dev
```

#### Custom Backend Service

If the built-in Restful implementation cannot meet your needs, you can customize your backend service. Please follow the steps below.

First, modify the backend service address to your custom address.

```ts title="packages/react-app/src/services/app/multiApp/restful.ts"
// For example, your custom backend service address is http://localhost:4567
const API_BASE_URL = 'http://localhost:4567'
```

Then, implement the following interfaces:

| Interface Name | Request Method | Interface Path | Request Parameters | Return Parameters |
|---------|----------|----------|----------|----------|
| Get App Configuration List | GET | `/apps` | None | `IDifyAppItem[]` |
| Get App Configuration Details | GET | `/apps/:id` | None | `IDifyAppItem` |
| Add App Configuration | POST | `/apps` | `IDifyAppItem` | None |
| Update App Configuration | PUT | `/apps/:id` | `IDifyAppItem` | None |
| Delete App Configuration | DELETE | `/apps/:id` | None | None |

### Next.js Version

#### Configuration Entry

```ts title="packages/nextjs-app/services/app/multiApp/index.ts"
# Use fs implementation
export * from "./fs";
```

#### Built-in Implementations

**1. Local File Storage**

Uses local files for storage, supports full CRUD, but has the risk of data loss.

Configuration example:

```json title="packages/nextjs-app/.dify-chat/storage/apps.json"
[
  {
    "id": "1751001348066",
    "info": {
      "name": "Chatflow Demo",
      "description": "",
      "tags": [
        "Parameter",
        "Test"
      ],
      "mode": "advanced-chat",
      "author_name": "Dify"
    },
    "requestConfig": {
      "apiBase": "https://api.dify.ai/v1",
      "apiKey": "app-xxx"
    },
    "answerForm": {
      "enabled": true,
      "feedbackText": "You submitted a form"
    },
    "inputParams": {
      "enableUpdateAfterCvstStarts": true
    },
    "extConfig": {
      "conversation": {
        "openingStatement": {
          "displayMode": "always"

      }
    }
  }

```

**2. Restful API**

Manages through API interfaces, supports full CRUD, recommended🌟

The default backend service address is `http://localhost:5300`. You can modify it according to your needs.

Start backend service:
