# Deploy - Using PM2

This article will introduce how to configure Nginx to deploy Dify Chat to production.

## Production Build

First, you need to build the production version:

<Tabs>
  <Tab label="React SPA">
```bash
pnpm build
```
	</Tab>
  <Tab label="Next.js">
```bash
pnpm build:next
```
	</Tab>
</Tabs>

## Nginx Configuration

<Tabs>
  <Tab label="React SPA">
```nginx title="nginx.conf"
# Note:
# Replace dify-chat.com with your domain name
# Replace /path/to/dify-chat/packages/react-app/dist/ with your build artifact path
http {
    server {
        listen 443 ssl;
        server_name dify-chat.com;

        ssl_certificate     /etc/nginx/ssl/dify-chat.com_bundle.crt;
        ssl_certificate_key /etc/nginx/ssl/dify-chat.com.key;

        location /dify-chat/ {
            alias /path/to/dify-chat/packages/react-app/dist/;
            try_files $uri $uri/ /dify-chat/index.html;
        }
    }
}
```
	</Tab>
  <Tab label="Next.js">
```nginx title="nginx.conf"
# Note:
# Replace dify-chat-next.com with your domain name
# Replace /path/to/dify-chat/packages/nextjs-app/ with your Next.js project root directory
http {
	server {
		listen 443 ssl;
		server_name dify-chat-next.com;
		root /path/to/dify-chat/packages/nextjs-app;

		ssl_certificate /etc/nginx/ssl/dify-chat-next.com_bundle.crt;
		ssl_certificate_key /etc/nginx/ssl/dify-chat-next.com.key;

		# Static resource cache
		location /_next/static/ {
			alias /path/to/dify-chat/packages/nextjs-app/.next/static/;
			expires 30d;
			access_log off;
		}

		# Reverse proxy all other requests to Next.js service
		location / {
			proxy_pass http://127.0.0.1:5300;
			proxy_http_version 1.1;
			proxy_set_header Upgrade $http_upgrade;
			proxy_set_header Connection 'upgrade';
			proxy_set_header Host $host;
			proxy_cache_bypass $http_upgrade;
		}
	}
}
```
	</Tab>
</Tabs>

### Start Next.js Project

If you are using the Next.js version, it is recommended to use PM2 to start the project.

Configure in PM2:

```js title="ecosystem.config.js"
module.exports = {
  apps: [
    {
      name: 'dify-chat-nextjs-app',
      cwd: '/path/to/dify-chat/packages/nextjs-app', // Working directory
      script: 'pnpm',
      args: 'start', // For example, nextjs startup command
      env: {
        NODE_ENV: 'production',
        PORT: 5300,
      },
    },
  ],
}
```

Start the project using PM2:

```bash
pm2 start /path/to/ecosystem.config.js
```
