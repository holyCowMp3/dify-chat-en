This section's content and Docker containerization deployment functionality are provided by community contributor @[@hitechbeijing](https://github.com/hitechbeijing).
:::

## Container Run

Enter the docker directory and start container orchestration:

```bash
docker compose up dify-chat -d
```

Browser access http://127.0.0.1:8080/dify-chat/

Containers expose http port 8080 and https port 8443 by default. You can modify the .env file to configure environment variables.

The default configured docker image is multi-app mode. If you need custom usage (such as single-app mode), please build the docker image yourself.

## Use certbot to automatically issue Let's Encrypt free SSL certificates

Before operating, please edit the .env file to modify the following parameters:

```bash
NGINX_HTTPS_ENABLED=true
# Domain name
NGINX_SERVER_NAME
# Domain name to apply for certificate
CERTBOT_DOMAIN
NGINX_ENABLE_CERTBOT_CHALLENGE=true
# Domain email, can be anything
CERTBOT_EMAIL
# More certificate application parameters, can be left empty
CERTBOT_OPTIONS
```

> Note: Please ensure that the domain name you configure can access your dify-chat site using port 80. For details, see: https://eff-certbot.readthedocs.io/en/latest/install.html#alternative-1-docker

Execute the command in the docker directory to automatically apply for and issue certificates:

```bash
docker-compose --profile certbot up
```

The issued certificates are in the [docker/certbot/conf/live/your-domain] directory.

Note: The certificate files in the above path are symlinks. If you need to use the certificates in other projects, you need to get the real certificate files from the [docker/certbot/conf/archive/your-domain] directory.

```txt
`privkey.pem`  : the private key for your certificate.
`fullchain.pem`: the certificate file used in most server software.
`chain.pem`    : used for OCSP stapling in Nginx >=1.3.7.
`cert.pem`     : will break many server configurations, and should not be used
                 without reading further documentation (see link below).
```
