# Opening Statement

Dify applications support configuring opening statements.

By default, the opening statement is displayed before each new conversation starts. After the user sends a message (i.e., the conversation starts), the opening statement will be hidden.

If you want to display the opening statement after the conversation starts, you can configure it in the application configuration:

Edit the application configuration in the interface, and set "Opening Statement Display Scenario" in "Conversation Configuration" to "Always Display".
